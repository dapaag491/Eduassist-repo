### 📖 Recommended Books
- **Build a Large Language Model (From Scratch)** by *Sebastian Raschka* - [Link](https://www.amazon.com/Build-Large-Language-Model-Scratch/dp/1633437167)
  > A comprehensive, step-by-step guide to building a GPT-like LLM from the ground up using PyTorch. This book directly supports the 'NanoGPT Explained' learning path by walking readers through tokenization, attention mechanisms, transformer architecture, pretraining, and fine-tuning. It is highly recommended for anyone seeking to identify and close knowledge gaps in the internal mechanics of models like NanoGPT, with clear code, diagrams, and conceptual explanations.
- **Deep Learning with PyTorch** by *Eli Stevens, Luca Antiga, Thomas Viehmann* - [Link](https://www.manning.com/books/deep-learning-with-pytorch)
  > Provides a thorough foundation in PyTorch, the framework most commonly used for implementing NanoGPT and similar educational projects. Covers tensors, autograd, model construction, and training loops. Ideal for closing knowledge gaps in the practical deep learning tooling required to understand, run, and modify NanoGPT code.
- **Hands-On Large Language Models** by *Jay Alammar, Maarten Grootendorst* - [Link](https://www.oreilly.com/library/view/hands-on-large-language/9781098150952/)
  > A practical, visually rich guide to modern LLM concepts, including transformer internals, token embeddings, attention, and instruction tuning. This book helps close the 'why it works' knowledge gap behind models like NanoGPT, with annotated diagrams and applied examples using open-source tooling.
- **Natural Language Processing with Transformers** by *Lewis Tunstall, Leandro von Werra, Thomas Wolf* - [Link](https://www.oreilly.com/library/view/natural-language-processing/9781098136789/)
  > Written by Hugging Face contributors, this book demystifies transformer architectures, including the GPT family. It covers attention, tokenization, and training pipelines, and includes chapters on training from scratch that map directly to the NanoGPT learning objective. Excellent for closing gaps in applied transformer knowledge.
- **The Illustrated Transformer** by *Jay Alammar* - [Link](http://jalammar.github.io/illustrated-transformer/)
  > While not a traditional book, this widely acclaimed illustrated guide and its companion piece 'The Illustrated GPT-2' are foundational reading for closing the conceptual knowledge gap behind transformer-based models. It visually breaks down self-attention, multi-head attention, and the full GPT block, which is the core architecture of NanoGPT. Frequently cited as the single most effective primer for visual learners.

### ✏️ Practice Problems

#### Tier A: Baby Level (Trivial)

##### 🔹 Identify the Stumbling Block in Q3
> Re-read the specific intermediate concept from Module 3 of the NanoGPT explanation that you previously answered incorrectly. Without looking at any external notes or solutions, write down (in plain text) exactly which sub-concept you misunderstood. Then, re-read the relevant section of the NanoGPT text and write a single, corrected sentence summarizing that concept in your own words. Verify your new understanding by checking it against the original explanation.


##### 🔹 Flashcard Creation for the Misunderstood Concept
> Create 5 question-and-answer flashcards specifically targeting the Q3 knowledge gap. Each flashcard should focus on a different facet of the missed concept (e.g., definition, purpose, common pitfalls, relationship to other parts of NanoGPT, and a simple numerical/token example). Save these to a file (e.g., `q3_review_flashcards.md`) so you can review them later.


#### Tier B: Novice Level (Intermediate)

##### 🔹 Hands-on Implementation of the Misunderstood Mechanism
> Write a small, self-contained Python script using PyTorch that implements only the specific mechanism you misunderstood in Q3 (e.g., causal masking, positional encoding addition, or the residual connection). Use dummy tensors shaped like NanoGPT inputs. Add print statements showing the input and output tensor shapes and values so you can visually verify the mechanism is behaving exactly as the text describes.


##### 🔹 Generate Distractor-Rich Practice Questions
> Write your own 10 multiple-choice questions about the Q3 concept. For each question, include four options where three are plausible but incorrect distractors designed to catch the same misunderstanding you had, and one is the correct answer. Add a brief explanation at the end of each question describing why the correct answer is right and why the distractors are wrong. This forces you to deeply analyze the boundaries of the concept.


#### Tier C: Warrior Level (Difficult)

##### 🔹 Trace and Annotate the NanoGPT Forward Pass
> Open the actual NanoGPT `model.py` or `train.py` source code. Trace the forward pass from raw input token IDs all the way to the output logits. For every line of code related to the Q3 concept you missed, add a comment block explaining: (1) what the line does, (2) what its tensor shape is at that point, and (3) why it is necessary for the mechanism you misunderstood. Commit this annotated version to a new branch in your local copy of the repository.


##### 🔹 Adversarial Test Case to Probe Your Understanding
> Design a test case that intentionally tries to break your understanding of the Q3 concept. For example, if Q3 was about attention masking, create an input sequence where the standard implementation might leak future information, and write a unit test asserting that the output does NOT contain that leaked information. If the test fails, you still have a gap. Document your findings, fix the gap, and ensure the test passes.


#### Tier D: Soldier Level (Expert)

##### 🔹 Teach the Concept to a Dummy Model
> Construct a detailed prompt (e.g., for an LLM or a rubber duck) asking it to explain the Q3 concept as if to a beginner. Critically, include the specific point where you previously failed. When the explanation comes back, identify any hallucinations, vagueness, or incorrect analogies. You must then refine the prompt iteratively until the explanation is flawless, demonstrating that you can now spot and correct subtle errors in the very area you once misunderstood.


##### 🔹 Write a Short Blog Post Bridging the Gap
> Write a 500-800 word technical blog post titled 'Why I Misunderstood [Concept X] in NanoGPT (and How I Fixed It)'. The post must include: a non-technical analogy, a clear technical explanation, code snippets demonstrating the before/after mental model, and a summary of how this concept integrates into the larger NanoGPT architecture. The goal is to prove you have fully synthesized the knowledge by explaining it cohesively from the ground up.
