- **ID:** `node-5`
- **Progress:** [ ] Completed

**Description:**

## 🔹 Module 6: Reference Management Software
- **ID:** `node-6`
- **Progress:** [ ] Completed

**Description:**

## 🔹 Module 7: Introduction to Data Analysis Software and Reproducible Code
- **ID:** `node-7`
- **Progress:** [ ] Completed

**Description:**
Explore Excel/Google Sheets, SPSS, R, and Python basics for research. Learn command-line fundamentals, package/environment management (conda, virtualenv), Jupyter and RMarkdown notebooks, and principles of reproducible code and literate programming.

## 🔹 Module 8: Qualitative vs Quantitative Research Design
- **ID:** `node-8`
- **Progress:** [ ] Completed

**Description:**
Understand differences, strengths, and appropriate applications of each approach. Learn sampling strategies, experimental design basics, power analysis, confounding, bias, and how to choose methods for your research question.

## 🔹 Module 9: Research Ethics, Data Governance, and Responsible AI
- **ID:** `node-9`
- **Progress:** [ ] Completed

**Description:**
Study IRB processes, plagiarism detection, copyright, licensing, data sharing agreements, and responsible use of AI/ML in research. Learn about bias, fairness, model interpretability, and citation and attribution best practices.

---

## 🔹 Module 10: Data Visualization and Presentation
- **ID:** `node-10`
- **Progress:** [ ] Completed

**Description:**
Create effective charts, graphs, and infographics using matplotlib, ggplot2, Tableau, Power BI, or Canva. Learn visualization principles, accessibility, color theory, and how to craft reproducible figures for publications and presentations.

## 🔹 Module 11: Advanced Statistical Analysis and Machine Learning Basics
- **ID:** `node-11`
- **Progress:** [ ] Completed

**Description:**
Dive into regression, ANOVA, correlation, hypothesis testing, model selection, cross-validation, and basic ML workflows. Practice with real datasets using R or Python (scikit-learn, TensorFlow/PyTorch) and learn evaluation metrics and pitfalls.

---

## 🔹 Module 12: Collaborative Research Platforms and Software Engineering Practices
- **ID:** `node-12`
- **Progress:** [ ] Completed

**Description:**
Explore Git, GitHub/GitLab, code review, continuous integration, issue tracking, Overleaf for LaTeX, and project management. Learn containerization (Docker), workflow managers (Snakemake, Nextflow), and basics of HPC and cloud computing for reproducible pipelines.

---

## 🔹 Module 13: Writing a Research Report and Reproducible Manuscripts
- **ID:** `node-13`
- **Progress:** [ ] Completed

**Description:**
Learn structure of academic papers, abstracts, methods, results, and discussion. Practice writing reproducible methods, including code and data availability statements, supplementary materials, and preparing figures and tables for submission.

---

## 🔹 Module 14: Peer Review, Preprints, and Research Dissemination
- **ID:** `node-14`
- **Progress:** [ ] Completed

**Description:**
Understand peer review, selecting journals, responding to reviewers, preprint servers, open access options, licensing, DOI assignment, and measuring impact (citations, altmetrics). Learn strategies for communicating results to nontechnical audiences.

---

## 🔹 Module 15: Capstone Project
- **ID:** `node-15`
- **Progress:** [ ] Completed

**Description:**
Apply learned skills in a comprehensive research project: define a question, locate and collect digital data, build a reproducible analysis pipeline (version control, environment, workflow manager), analyze results, and present findings in a reproducible report with code and data links.

---

## 🔹 Module 16: Computational Biology Research
- **ID:** `node-16`
- **Progress:** [ ] Completed

**Description:**
Learn how biological research can be performed entirely on a computer. Topics include genomics (variant analysis, assembly, annotation), transcriptomics (bulk and single-cell RNA-seq), proteomics, protein structure prediction and design (AlphaFold, ProteinMPNN), molecular docking, molecular dynamics, systems biology, phylogenetics, and ML for biology. Tools and practices: BLAST, DESeq2, Seurat/Scanpy, AlphaFold DB, GROMACS/OpenMM, DeepChem, reproducible pipelines (Snakemake/Nextflow), and public datasets (GEO, SRA, PDB, Human Cell Atlas).

---

## 🔹 Module 17: Computational Materials Science
- **ID:** `node-17`
- **Progress:** [ ] Completed

**Description:**
Study how materials can be designed, simulated, and analyzed digitally. Topics include electronic structure (DFT), molecular dynamics, crystal structure prediction, defect and surface modeling, phase diagrams (CALPHAD), finite element modeling, and materials informatics (GNNs, surrogate models). Tools and practices: VASP/Quantum ESPRESSO, LAMMPS, GPAW, COMSOL/FEniCS, Matminer, Materials Project, OQMD, NOMAD, and reproducible workflows for high-throughput screening.

---

## 🔹 Module 18: Solar Energy and Solar Cell Simulation
- **ID:** `node-18`
- **Progress:** [ ] Completed

**Description:**
Explore solar cell efficiency modeling, device physics, optical simulations, and system-level modeling. Topics include Shockley–Queisser limits, drift-diffusion device simulation, thin-film optics, light trapping, perovskite and tandem cell modeling, degradation and stability modeling, and energy systems integration (PV + storage). Tools and datasets: SCAPS-1D, TCAD, MEEP, TMM, SAM (NREL), PVDAQ, Materials Project, and ML approaches for materials and device optimization.
