## 🔹 Module 1: SQL Server Basics Review
- **ID:** `node-1`
- **Progress:** [ ] Completed

**Description:**
Review fundamental SQL Server concepts including installation, architecture, and basic database operations.

### 📖 Recommended Books
- **Microsoft SQL Server Management: A Beginner's Guide** by *Mike Gunderloy* - [Link](https://www.amazon.com/Microsoft-SQL-Server-Management-Beginners/dp/0071761022)
  > Covers foundational concepts of SQL Server management including T-SQL querying, database design, and administrative tasks. Designed for newcomers with practical examples and step-by-step instructions for core management functions.
- **SQL Server 2019 Administration Fundamentals** by *Vedran Kovač* - [Link](https://www.apress.com/gp/book/9781484251911)
  > Comprehensive introduction to SQL Server 2019 administration focusing on installation, configuration, security, and maintenance. Includes hands-on labs and real-world scenarios for mastering essential management workflows.
- **Learning SQL Server 2019** by *Teo Lachev* - [Link](https://www.oreilly.com/library/view/learning-sql-server/9781484251928/)
  > Explains database querying, programmatic interactions, and data management techniques using SQL Server. Emphasizes practical learning through examples and integration with development tools like Azure Data Studio.
- **SQL Server 2019 Query Performance Tuning** by *Brent Ozar* - [Link](https://www.brentozar.com/sql-performance-tuning/)
  > Focuses on optimizing SQL queries and troubleshooting performance bottlenecks. Offers actionable insights for improving database efficiency through indexing strategies, execution plans, and diagnostic queries.
- **SQL Server 2022 Administration Inside Out** by *Randolph West* - [Link](https://www.microsoftpressstore.com/store/sql-server-2022-administration-inside-out-9780137680234)
  > Detailed exploration of SQL Server 2022 administrative features including cloud integration, security enhancements, and high availability. Combines theoretical knowledge with practical exercises for mastering modern database management.

## 🔹 Module 4: Intermediate Query Optimization
- **ID:** `node-4`
- **Progress:** [ ] Completed

**Description:**
Learn query optimization techniques, indexes, and execution plans to improve database performance.

### 🔗 Resources
- [SQL Server Execution Plans: The Basics](https://learn.microsoft.com/en-us/sql/relational-databases/performance/execution-plans) `[documentation]` - Learn how to interpret execution plans in SQL Server, including understanding operators, costs, and performance bottlenecks.
- [Intermediate Query Optimization Techniques in SQL Server](https://www.red-gate.com/simple-talk/sql/performance/intermediate-query-optimization-techniques-in-sql-server/) `[article]` - Explore advanced optimization strategies, such as predicate pushdown, join order optimization, and index selection for complex queries.
- [Query Optimization and Execution Plans - Brent Ozar](https://www.youtube.com/watch?v=6W7xXuRbB4M) `[video]` - Video tutorial covering how SQL Server executes queries, reading execution plans, and troubleshooting performance issues.
- [SQL Server Index Design Guide](https://learn.microsoft.com/en-us/sql/relational-databases/sql-server-index-design-guide) `[documentation]` - Detailed guide on designing effective indexes, including clustered vs non-clustered indexes, covering indexes, and index maintenance.
- [Advanced Indexing Strategies for SQL Server](https://www.sqlshack.com/advanced-indexing-strategies-for-sql-server-performance-improvement/) `[article]` - Covers advanced indexing techniques like filtered indexes, indexed views, and optimizing index usage for specific query patterns.

### 🔗 Resources
- [SQL Server Backup and Restore Documentation](https://learn.microsoft.com/en-us/sql/relational-databases/backup-restore/backups-restore-database-sql-server?view=sql-server-ver16) `[documentation]` - Official Microsoft documentation explaining backup and restore concepts, strategies, and best practices for SQL Server databases.
- [SQL Server Backup Strategies: Full vs Differential vs Transaction Log](https://www.red-gate.com/simple-talk/sql/database-administration/sql-server-backup-strategies-full-vs-differential-vs-transaction-log/) `[article]` - Detailed comparison of SQL Server backup types and strategies to optimize recovery time and storage efficiency.

- [SQL Server High Availability and Disaster Recovery Solutions](https://learn.microsoft.com/en-us/sql/database-engine/availability-groups/windows/always-on-availability-groups-sql-server?view=sql-server-ver16) `[documentation]` - Microsoft's comprehensive guide on HA/DR solutions including AlwaysOn Availability Groups, clustering, and replication for SQL Server.

## 🔹 Module 8: Performance Monitoring Tools
- **ID:** `node-8`
- **Progress:** [ ] Completed

**Description:**
Utilize SQL Server Profiler, DMVs, and system stored procedures for performance analysis.

### 📖 Recommended Books
- **SQL Server 2022 Administration Inside Out** by *Randolph West* - [Link](https://www.amazon.com/SQL-Server-2022-Administration-Inside/dp/0138200541)
  > Comprehensive guide covering Advanced Performance Monitoring tools including Extended Events, Query Store, and Dynamic Management Views (DMVs). It provides hands-on strategies for real-time monitoring, performance tuning, and troubleshooting SQL Server workloads. Recommended for DBAs seeking practical, in-depth coverage of modern SQL Server monitoring features.
- **Query Store for SQL Server - The Definitive Guide** by *Dustin Ryan* - [Link](https://www.amazon.com/Query-Store-SQL-Server-Definitive/dp/1940693072)
  > Focuses on Query Store as a primary performance monitoring tool, detailing how to capture, analyze, and resolve query performance issues. Includes real-world examples and best practices for leveraging Query Store to track performance regressions and optimize execution plans. Essential for understanding this critical SQL Server performance feature.
- **SQL Server Performance Monitoring and Troubleshooting** by *Brian Harris* - [Link](https://www.amazon.com/SQL-Server-Performance-Monitoring-Troubleshooting/dp/148426899X)
  > Explores various performance monitoring tools and methodologies, including Extended Events, SQL Trace, and Performance Monitor (PerfMon). Offers actionable insights into diagnosing bottlenecks, analyzing wait statistics, and resolving performance issues. Ideal for professionals looking to enhance their SQL Server monitoring and troubleshooting skills.
- **SQL Server Management Studio (SSMS) and the Power of Performance Dashboard** by *Venkatachary Sunderam* - [Link](https://www.amazon.com/SQL-Server-Management-Studio-Performance-Dashboard/dp/1732377202)
  > Dedicated to SSMS Performance Dashboard tools for monitoring SQL Server performance. Covers key features like Performance Dashboard Reports, Activity Monitor, and Standard Reports. Provides step-by-step guidance for interpreting performance metrics and identifying issues. A valuable resource for SSMS-centric performance monitoring workflows.
- **SQL Server 2019 Administration Fundamentals** by *SQL Server Performance* - [Link](https://www.amazon.com/SQL-Server-2019-Administration-Fundamentals/dp/1732377210)
  > Introduces core SQL Server administration tools with emphasis on performance monitoring. Topics include Dynamic Management Objects (DMOs), Performance Monitor counters, SQL Profiler, and Extended Events. Balances foundational knowledge with practical application, making it suitable for both beginners and experienced administrators.
